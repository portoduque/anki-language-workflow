# 10 — Statistics, Filtered Decks, and Leeches

## Statistics

Anki's statistics include:
- reviews;
- time;
- card counts;
- future due load;
- intervals;
- answer-button usage;
- hourly performance;
- calendar activity;
- FSRS stability/difficulty/retrievability;
- true retention.

For FSRS, prefer multi-week/month views over a single day's noisy result.

## True retention

Again is counted as failure; Hard/Good/Easy are passing recalls. If true retention materially diverges from FSRS desired retention over meaningful periods, investigate:
- parameter optimization;
- different presets for substantially different material;
- leeches;
- answer-button misuse.

## Filtered decks

Use filtered decks for temporary targeted study based on search criteria. They are better than permanently creating many micro-decks for every temporary study goal.

## Leeches

Leeches are cards repeatedly forgotten.

A leech is usually a signal to:
- reformulate the card;
- split overloaded content;
- add missing context;
- fix ambiguity;
- improve understanding;
- suspend low-value material.

For this project, repeated failure should trigger **card redesign**, not blindly more repetitions.
